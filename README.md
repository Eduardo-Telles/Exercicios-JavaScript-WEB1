## 🎯 Sobre este repositório

Aqui ficam os exercícios de JavaScript da disciplina WEB1. O objetivo é registrar minha evolução na linguagem, praticar boas práticas (nomes claros, código indentado, comentários) e manter tudo organizado em um só lugar.

Estou atualizando aos poucos, então novos exercícios aparecem com frequência.

## ▶️ Como executar

Os exercícios podem rodar de duas formas, dependendo do tipo.

**Exercícios com página (HTML + JavaScript):** abra o arquivo `index.html` do exercício no navegador com dois cliques. Se usa o VS Code, a extensão **Live Server** atualiza a página automaticamente enquanto você edita.

**Exercícios só de JavaScript (sem página):** precisam do [Node.js](https://nodejs.org/) instalado.

```bash
git clone https://github.com/Eduardo-Telles/NOME-DO-REPOSITORIO.git
cd NOME-DO-REPOSITORIO
node 01-basico/nome_do_arquivo.js
```

Troque `01-basico/nome_do_arquivo.js` pelo caminho do exercício que quiser rodar. Para ver o resultado de `console.log` em uma página, abra o console do navegador com `F12`.
